# Saiket Systems Internship – Python Development Tasks

This repository contains my completed tasks for the **Saiket Systems Python Development Internship**, covering multiple core Python concepts such as file handling, OOP, GUI development, basic automation, and problem-solving.

---

Each folder contains one Python project based on internship requirements.

## Task Overview

### **Task 1 – To-Do List (Tkinter GUI)**
A GUI application to:
- Add, delete, clear tasks  
- Mark tasks as completed  
- Display progress  
Uses Tkinter for UI + JSON/text for data handling.

---

### **Task 2 – Number Guessing Game**
A console-based guessing game:
- User gets 5 attempts  
- Program gives HIGH/LOW hints  
- Replay option included  
Uses loops, conditions, and random module.

---

### **Task 3 – Basic File Handling Application**
A menu-driven program that allows:
- Reading file content  
- Searching a word (case-insensitive)  
- Find and replace with backup  
- Regex-based word detection  
Uses exceptions, regex, pathlib, and shutil.

---

### **Task 4 – Basic Web Scraper**
A simple Python web scraper that:
- Fetches webpage HTML  
- Extracts required tags/data  
Introduces web requests and web content parsing.

---

### **Task 5 – Currency Converter**
A Python tool to:
- Convert amounts between currencies  
- Use fixed or API-based exchange rates  
Demonstrates calculations and optional API usage.

---

### **Task 6 – Word Count Tool**
Reads a `.txt` file and calculates:
- Total words  
- Total lines  
- Total characters  
- Word frequency (Top 5 repeated words)  
Uses dictionaries, sorting, and file handling.
